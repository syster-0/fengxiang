## 信号

小红书与抖音出现多条针对 **T7M Pro / T7M Ultra** 的用户抱怨，
措辞高度集中在安装、支架、贴墙三个环节，而非画质或质量。

原始措辞（09-15 至 09-16 窗口，emotion 标记为悲伤与愤怒）：
「我真的跪了」「装修多留意」「别被『贴墙电视』忽悠了」「慎重一点，能劝则劝」
「跟风入 T7M Ultra，安装才发现坑」。

**判定：素材级问题，非产品级问题。**

## 观测窗口

- 基线窗口：2026-09-15 ~ 09-16（首次发现）
- 升级观察窗：**3 日内**
- 处置时限：**24 小时内核实**

## 强度

| 维度 | 评估 |
|---|---|
| 当前强度 | **低—中**（多条不同账号独立发布，但样本量小） |
| 传播载体 | 小红书 + 抖音（短视频平台，**内容留存久、搜索可见度高**） |
| 直接影响 | 换机决策路径 —— 用户搜「T7M Pro 怎么样」时会被命中 |
| 情绪标签 | 悲伤 + 愤怒 |
| 事实内核 | **购前未被告知默认挂架不支持后插拔线**（见 `spec/wall-mount-tiers`） |

**关键判断**：抱怨集中在安装环节说明这是**最容易低成本解决的类型**。
若问题出在安装服务标准或宣传口径，修复成本远低于硬件缺陷。

## 衰减

- **自然衰减快**：素材级问题，无持续策源，若无新增会自然沉底。
- **但搜索可见性长尾**：小红书/抖音的图文与短视频在搜索结果中留存时间远长于新闻，
  会在未来数月持续影响换机决策。
- **放大条件**：出现「退机 / 维权 / 索赔」字眼，或同类帖数上升 → 加速升级。

## 建议动作

1. **24 小时内**：由售后与渠道团队抽样核实这批帖子的真实售后工单归属 ——
   拉取型号、购买渠道、安装服务商三维度，判断是**个别服务商行为**还是**区域性安装规范问题**。
2. **同步动作（内容侧）**：所有生成内容中的「真贴墙」相关表述，
   一律补上挂架档位前提（见 `claim/wall-flush-slim` 反击话术）。这是零成本的风险对冲。
3. **不做的动作**：不对个案下「乱收费」定性（`risk/absolute-superlative`）；
   不在公开渠道与发帖用户对线。
4. **升级触发条件**：3 日内同类负面帖增至 10 条以上，
   或出现「退机 / 维权 / 索赔」字眼 → 升级为 L2 处理并统一对外口径。
5. **回填**：核实结果回填至 `gap/install-service-standard`，补全该缺口的「状态」字段。
