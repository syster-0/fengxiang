# tvop-distill · 仓颉 RIA-TV++ 蒸馏

## 何时使用

- 有一批语料，要把它变成**可复用的概念**而不是一堆摘抄。
- 要抽象出「评论范式」「声部人格」「对立轴」「厂商话术」。
- 要给概念做压力测试（triggers / decoys / negatives）。

打分走 `$tvop-taste`；落库与校验走 `$tvop-okf`。本 skill 只管**怎么蒸**。

## 七阶段

### ① Adler 整体理解
先写一份 `source/` 概念：**结构 → 解释 → 批判 → 应用**四步。
**不许清洗矛盾。** 语料里互相打架的说法要原样保留，那正是信息。

### ② 五提取器
从语料里抽五种成分，不是抽「要点」：

| 成分 | 抽什么 |
|---|---|
| 论点 | 他主张什么 |
| 论据 | 他拿什么撑（**必须带数字与条件**） |
| 限定条件 | 他自己补了什么括号 |
| 让步 | 他承认了对方什么 |
| 收口 | 他最后落在哪句话 |

**让步与限定条件是本领域最有价值的成分。** 高可信度的中文评论自带条件限定；
AI 生成的内容通常只给单向结论 —— 这是区分人味的核心信号。

### ③ 三重验证
- **V1 语料是否支持**：这条概念能不能找到原句出处。
- **V2 是否与已有概念冲突**：冲突不一定是错，可能是新轴 —— 但要显式登记。
- **V3 是否可被追问而不崩**：想象最刻薄的数码党追问它，能不能站住。

### ④ 晋级门
**过不了三重验证的概念不进库。** 不过的概念登记为 `gap/`，写明缺什么、去哪补。
**未入库不使用** —— 不要先拿去写评论。

### ⑤ RIA++ 能力卡
按概念类型填固定骨架（`tvop spec types` 会列出每种类型的 BodyShape）：

- **Comment Pattern**：R 原文样本 / I 骨架抽象 / A1 触发场景 / A2 迁移 / E 可直接用的句式 / B 禁用边界
- **Voice Persona**：R 语料来源 / I 表达 DNA / A1 开场与收尾 / E 生成参数 / B 越界特征
- **Tension Axis**：议题 / A 侧论据 / B 侧论据 / 中立带 / 可引战点 / 合规边界
- **Market Claim**：原话术 / 事实内核 / 已证实的部分 / 可反驳点 / 反击话术
- **Audience Segment**：切片 / 决策驱动力 / 关心参数 / 语言习惯 / 常见异议

### ⑥ Zettelkasten 链接
每个概念至少双向出链 2 条，写进 `atelier.links`。
孤立概念在召回里排不上号，也长不出新东西。

### ⑦ 压力测试
每个概念写三组用例，**一个都不能省**：

```json
{
  "concept": "voice/bili-geek",
  "triggers": ["用 B 站语气拆解参数", "写一段实测评论"],
  "decoys":   ["写一条贴吧长贴", "写一句高赞短句"],
  "negatives":["voice/hot-consensus", "voice/douyin-conflict"]
}
```

- `triggers` 该命中；
- `decoys` 是**相近但该拒绝**的（比如同样是「写评论」但声部不同）—— 这是最容易被跳过、也最能筛掉模糊概念的一组；
- `negatives` 是兄弟概念互斥用例。

## 工具

```bash
tvop distill plan                # 生成本轮蒸馏计划
tvop spec types                  # 查每种类型的必填字段与正文骨架
tvop crawl tension               # 从语料提对立轴候选
tvop okf new  --type ... --slug ...   # 建概念
tvop okf test --id ... --triggers "…" --decoys "…" --negatives "…"
```

## 三条质量红线

1. **概括盖数据。** 「表现非常出色」盖掉本该给的型号与数字 —— 违反人味算子，直接回炉。
2. **清洗负样本。** 把「肤色偏红」「没标配挂架」这类短板删掉 —— 概念可信度归零。
3. **单向结论。** 没有让步、没有限定条件的论断，一律按 AI 味处理。

## 输出规范

- 报：本轮蒸出多少概念、哪些过了三重验证、哪些登记为缺口、缺口缺什么。
- 每个概念给一句话摘要 + 它的声部归属 + 链接了谁。
- 缺口要具体到「缺什么数据、去哪补」，不写「资料不足」。
